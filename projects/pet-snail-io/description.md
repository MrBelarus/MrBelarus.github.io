### 🎯 Description
If your body touches another snail, the game will instantly over and you have to start again! BUT! You can outsmart others and make them crash into You!
Can you become the biggest and slipperiest Snail?

### ⚡ Features
* 50 unique snails
* 3 game modes
* Fun gameplay
