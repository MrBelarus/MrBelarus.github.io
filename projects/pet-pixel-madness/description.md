### 🎯 Description
This relaxing, colorful game requires nothing more than shooting at the image. Each level refers to a specific theme (cars, memes, gaming), every weapon offers unique firing mechanics and visuals, and the destruction is highly satisfying thanks to the physics simulation of falling objects.

### ⚡ Features
* Destroy images with weapons
* A lot of unique weapons
* A lot of image levels
