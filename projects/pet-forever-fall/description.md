### 🎯 Description
Forever Fall is a fast-paced puzzle game with the aim of building the highest tower.
Move, rotate the figures, climb higher and higher! Compete with your friends and conquer new heights!

### ⚡ Features
* Leaderboards
* Achievements
* Endless mode
* Challenges
